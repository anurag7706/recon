# Recon Engine – OSINT & Google Dork Generator

Recon Engine is a **client-side reconnaissance toolkit** built for **security researchers, bug bounty hunters, and OSINT analysts**. It helps generate advanced Google dorks and perform quick domain-based intelligence gathering.

---

## ⚡ Features

- 🔍 Custom Google Dork Builder (site, filetype, inurl, intitle, intext)
- 🧠 Domain Recon (subdomains, admin panels, sensitive files, APIs)
- 🌐 OSINT Multi-source links (VirusTotal, Shodan, Wayback, OTX, Censys, etc.)
- 🛡️ VirusTotal domain lookup (API + GUI)
- 📜 Search history (local storage)
- 🎨 Clean UI with dark/light mode
